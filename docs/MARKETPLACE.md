# Controlled plugin marketplace

**Status: concept / stub only. Not live. Do not claim a working store.**

See `docs/ARCHITECTURE.md` §5.6 and §8.

## What it is (when built)

A catalog of plugins / extensions **we** build or vendor, review, and publish through our channel — optional per org.

## What it is not

- Arbitrary third-party uploads
- Unsigned blobs
- An open sideload free-for-all

## Before any public “install plugin”

Signing keys, update/revoke story, and security review of the supply chain.

## Repo placeholder

Empty `catalog/` — no install UX that pretends plugins are available today.
